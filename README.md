# 🧠 DataMind AI

## Intelligent End-to-End Data Science Copilot

DataMind AI is an AI-powered Data Science assistant that helps users:

- 📂 Upload CSV/Excel datasets
- 📊 Perform Automated EDA
- 📈 Generate Visualizations
- 🤖 Train Machine Learning Models
- 💬 Chat with Data using Gemini
- 📄 Ask Questions from PDFs using RAG
- 👥 Multi-Agent Workflow

## Tech Stack

- Python
- Streamlit
- Pandas
- Scikit-learn
- LangChain
- Google Gemini
- FAISS
- CrewAI
